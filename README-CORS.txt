Transmission BTC CORS + обычная Lampa

СТАТУС: исходники и workflow подготовлены. APK не собран и не проверен на устройстве.
Эта работа использует старый Android-порт Transmission 1.3.10 и его зависимости.
Совместимость сборки с текущим GitHub runner ещё требуется проверить.

Загрузить содержимое этой папки в корень существующего репозитория
deadmp3/lampa-transmission, включая .github/workflows/build-transmission-cors.yml.
Существующие файлы для Lampa v1.4 не изменять: новый файл расширения называется иначе.
Actions -> Build Transmission BTC CORS APK -> Run workflow.
После успешного выполнения артефакт: transmission-btc-cors-apk.

Новая программа Transmission BTC CORS ставится рядом с обычным Transmission BTC.
Её порты: RPC 9191, UPnP HTTP 9192. Раздачи и каталог настроек независимые.
Исходные скачанные файлы не удаляются, но новая программа не получает автоматически
раздачи и права на частный каталог старого приложения. Для первого теста добавить
небольшой собственный тестовый торрент и выбрать доступный общий каталог загрузок.
Для переноса раздач потребуется отдельно добавить исходные .torrent и выполнить
проверку файлов по прежнему общему каталогу; приватный каталог Android другого
приложения может быть недоступен.

Включить UPnP MediaServer в НОВОЙ программе для просмотра видео.
В обычной Lampa настроить адрес запуска http://bylampa.online и установить
https://deadmp3.github.io/lampa-transmission/transmission-cors.js
Это одна устанавливаемая ссылка: она загружает исходный LME Torrent Manager
с официального адреса автора и добавляет воспроизведение готовых видео.
В этой Lampa отключить другие копии Torrent Manager и старые native-fix-патчи,
чтобы не было повторной регистрации. Затем перезапустить Lampa.
Клиент Transmission; Address http://127.0.0.1:9191; RPC Path /transmission/rpc;
Прокси Нет; адрес видео http://127.0.0.1:9192. Логин/пароль согласно новому BTC.

CORS разрешён только для http(s)://bylampa.online и http(s)://lampa.mx,
а также запросов из собственного веб-интерфейса RPC. Для другого источника Lampa
нужно добавить его точный Origin в cors/LampaCorsPolicy.h и пересобрать APK.
Произвольные сайты и Origin null не допускаются. Проверки пароля, IP и Session ID
не отключаются. Это НЕ гарантирует поддержку любой старой WebView/браузера.

JavaScript на Pages не содержит Session ID и не обращается к компьютеру.
Проверка перед переходом: список, возобновление/пауза собственной тестовой раздачи,
просмотр готового видео, повтор после перезапуска нового Transmission и Lampa.
Оригинальную рабочую пару Lampa/Transmission сохранять до проверки новой.

При публикации JavaScript действует существующий workflow Pages, который раздаёт site/.
Debug APK предназначен для теста. Для обновлений без переустановки нужен постоянный
собственный ключ подписи; не публикуйте приватный ключ в репозитории.
